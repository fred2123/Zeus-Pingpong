# Zeus Pingpong ⚡

A mobile-friendly pingpong game in a single HTML file. Drag to move your paddle, beat Poseidon to 7 points, and charge the ball with lightning on long rallies.

- Three difficulty levels: Mortal, Hero, Olympian
- Touch controls (arrow keys on desktop, `P`/`Esc` to pause)
- Sound, sparks, lightning effects and a win/loss record per level

**Play:** open `index.html` in a browser, or enable GitHub Pages for this repo.

## Install on iPhone
1. Open https://fred2123.github.io/Zeus-Pingpong/ in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Launch Zeus Pingpong from your home screen — full screen, works offline.
